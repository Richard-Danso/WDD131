Site Name

Name: TechGear Hub

Reasoning: I chose this name because the website is designed as a central hub for technology enthusiasts seeking reviews, specs, and gear recommendations for modern workplace electronics.

Optional Domain Availability: techgearhub.org

Site Purpose

The site serves as a resource for remote workers and tech hobbyists to discover quality computer peripherals, monitor setups, and workspace accessories. It provides product reviews, interactive comparison tools, and curated buying guides.

Target Audience Scenarios

  • Scenario 1: What ergonomic mechanical keyboard should I buy if I work long hours remotely?
  • Scenario 2: Where can I find a comparison of dual-monitor desk setups for under $300?

Color Palette

This site plan document actively demonstrates the chosen color scheme:

Primary Color #1f2937 Used for headers, navigation backgrounds, and primary accents.
Secondary Color #3b82f6 Used for buttons, links, and highlighted borders.
Accent / Background #f3f4f6 Used for section backgrounds and card layouts.

Typography

The site utilizes two complementary Google Fonts:

  • Heading Font: "Montserrat", sans-serif (Used for all headings: H1, H2, H3)
  • Body Font: "Open Sans", sans-serif (Used for paragraphs, list items, and form elements)
